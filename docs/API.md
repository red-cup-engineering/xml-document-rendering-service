## Verified acceptance cases

Specification basis. XML 1.0 and Namespaces 1.0 ordered documents carried in UTF-8 with SignCell source evidence.

| Case | Check | Behavior |
| --- | --- | --- |
| ` XML-NAMESPACE-REFUSAL ` | source refusal | Malformed markup and namespace failures produce diagnostics and refuse conversions. |
| ` XML-SOURCE-REPLAY ` | consumer example | The installed reader identifies exact XML source bytes and the writer validates the emitted document. |
